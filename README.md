# MEWO ADVENTURE

Пиксельный платформер на HTML / CSS / Vanilla JS (Canvas, ES-модули).

## Управление

* **Клавиатура:** ← → / A D — ходьба, Space / W — прыжок
* **Телефон:** экранные кнопки ◀ ▶ ▲ (удержание)

## Цель

Собери **5 цветов**, дойди до домика. Рекорд — лучшее время прохождения.

## Нейросеть и промпты

Игра создана с помощью Grok (xAI). Основные шаги:

1. Каркас Canvas + персонаж + земля
2. Движение, прыжок, гравитация, dt
3. Платформы и столкновения
4. Единый requestAnimationFrame + visibility
5. Предметы, опасность, победа/поражение
6. Старт/пауза/рестарт, localStorage
7. Спрайты, мобильные кнопки, оформление

## Графика

Спрайты из папки assets (пользовательские изображения). Звука нет.
